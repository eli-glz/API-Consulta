# Continuidad del proyecto

Antes de analizar, modificar o ejecutar este repositorio, leer completo
`CONTEXTO_PROYECTO.md`. Ese archivo contiene el ultimo estado validado y evita
repetir el relevamiento completo del proyecto.

Usar el contexto como punto de partida. Verificar de nuevo solamente los datos
que puedan haber cambiado desde la ultima sesion o cuando exista una
inconsistencia concreta.

Despues de cambios sustanciales, actualizar `CONTEXTO_PROYECTO.md` con el nuevo
estado, pruebas realizadas y pendientes. Nunca guardar claves ni contrasenas en
archivos del repositorio.

La base Oracle es estrictamente de solo lectura: no crear, modificar ni eliminar
datos u objetos de la base.
